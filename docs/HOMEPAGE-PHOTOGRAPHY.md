# Homepage photography

Updated 2026-10-11 following the request to replace the Atithi hero and use an abstract project detail in the closing invitation.

## Current selection

- **Opening:** Raju Omelet Albion, Etobicoke / `_Z7A8803.jpg`. Daylight, curved yellow seating, timber flooring, a chandelier and the service counter provide a warm view of the delivered interior. Compared the Albion and Kitchener shoots with the previously reviewed Jimmy John's Windsor photographs. Albion's landscape image was selected for its light and architectural composition.
- **Closing:** Jay Bhavani, Etobicoke / `_Z7A8697.jpg`. The webpage frames the geometric ceiling, blue-grey trim, patterned white panels and recessed lighting as an abstract architectural study. Its caption identifies this detail rather than describing an entire restaurant.
- Both retain attribution to prior work under LifeBuild Canada. No new scope, date, credential or outcome was added.

## Presentation

- The hero has responsive 800px and 1600px progressive JPEG exports. Its phone focal point favours the curved yellow seating and service counter.
- The closing image uses a 2400px progressive JPEG export for its deliberate close framing. CSS positions and enlarges the original photograph within the existing frame. There is no retouching, generated content, colour alteration or zoom animation.
- All three new assets are below the existing 400 KB image budget.
- The hero project label is text because the site has no Raju project page. It does not link to an unrelated project. Existing portfolio navigation is preserved.
